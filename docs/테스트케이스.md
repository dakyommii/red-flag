# 부동산 사기 추리·검증 게임 — 테스트케이스

## 1. 개요

- **대상**: `backend`(FastAPI) + `frontend`(React/Vite) + `data/cases/*.json`
- **참고 문서**: `부동산_사기_추리게임_MVP_설계문서.md`, `docs/구현_단계별_프롬프트.md`
- **환경**: 로컬 개발 서버 — backend `http://localhost:8010`, frontend `http://localhost:5173`
- **표기**: 우선순위 P0(핵심/차단) · P1(주요) · P2(부가)

### JEONSE_003 상세 (회귀 테스트 기본 CASE)

- Evidence: `REG_02`→`TRUST_REGISTRATION`, `CTR_01`→`VERIFICATION_BLOCK`, `AGT_02`→`URGENCY`
- NPC 발언: `S01`="집주인이 직접 계약하면 아무 문제 없습니다.", `S02`="보증보험도 가입 가능한 안전한 매물입니다."
- 모순: `C01`(S01↔TRUST_REGISTRATION, 15점), `C02`(S02↔VERIFICATION_BLOCK, 10점)
- `hidden_truth.risk_patterns` = [TRUST_REGISTRATION, VERIFICATION_BLOCK, URGENCY]
- `ending_options` 점수: SAFE_TO_PROCEED 5 / NEED_MORE_VERIFICATION 15 / STOP_CONTRACT 12

## 7. AI 자유발화 평가 (Evaluator) — 기능 제거됨

`POST /game/{id}/free_action` 엔드포인트와 조사 화면의 "지금까지의 판단을 입력해보세요" 입력창은
제거되었습니다. 입력해도 최종 판단이나 점수에 반영되지 않아 플레이어가 굳이 사용할 이유가 없다는
피드백에 따라, 관련 백엔드 코드(`evaluate_free_action`, `FreeActionResult`, `safe_actions` 상태 노출)와
프론트엔드 UI를 모두 삭제했습니다. TC-EVAL-01~05는 더 이상 유효하지 않습니다.
